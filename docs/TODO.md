# Delivery outcomes

## 1. Original visual identity and art direction
- [x] The website must NOT look like a generic SaaS template, generic agency template, Webflow clone, AI-generated landing page, common startup website, or copied existing website.
- [x] Establish the creative concept and visual system before designing page sections. Use selective Awwwards-inspired editorial composition and Mobbin-level UX clarity without directly copying any site.
- [x] Use an original, coherent art direction with a single recurring visual motif; avoid generic blue SaaS gradients, random purple blobs, excessive glowing cards, generic glassmorphism, dozens of rounded cards, predictable icon grids, template-looking testimonial cards, stock marketing illustrations, meaningless abstract 3D objects, excessive pill UI, repetitive left-text/right-image sections, AI-looking dashboard mockups, and visual effects without strategic purpose.
- [x] Establish and apply creative direction, typography system, color system, spacing system, grid, motion language, imagery direction, button style, and reusable UI components.
- [x] Typography carries a major part of the identity: oversized headlines, short lines, strong display/support contrast, tight but legible headline leading, considered letter spacing, and concise specific contemporary copy. Avoid marketing clichés, corporate fluff, empty superlatives and buzzword soup; prefer tangible language about pipeline, acquisition cost, conversion, margin, retention, creative performance, revenue, distribution, demand, experimentation, lifetime value, attribution and velocity.

- [x] Replace the sparse/abstract image placeholders with six distinct, legally reusable Pexels photographs: (1) the warm agency-planning hero, (2) a wide creative/color-planning image after Services, (3) an illustrative featured-case-study work scene, and (4–6) distinct image-led visuals for the three selected-work formats. Add responsive object-fit/object-position crops, use eager loading only for the hero and lazy loading below it, and avoid empty visual gaps. Record each exact image source page, photographer and Pexels license in the project. Label all stock imagery as illustrative—not PAYOFF staff, a client asset, a client win or endorsement. Pinterest may guide the visual mood, but do not reuse unlicensed Pinterest reposts or watermarked Unsplash+ imagery.

- [x] Build a substantial experience whose visitor journey is curiosity → understanding → credibility → proof → desire → reduced risk → conversion; the agency should communicate that it understands growth, has a repeatable process, can show measurable results, understands the client's business rather than only selling services, has expertise/proof/methodology that reduce risk, is premium but approachable, and cares about revenue/business outcomes rather than vanity metrics.
- [x] Provide premium sticky navigation with Work, Services, Approach, About and Insights links plus a primary booking CTA. Navigation begins transparent and adapts to a compact background container after scrolling.
- [x] Include real trust mechanisms throughout: quantitative proof with honest provenance, case studies, specific methodology, client signals, testimonials only when approved, clear deliverables, reporting transparency, expertise, strategic point of view, process clarity, FAQ objections, client qualification and performance metrics. Do not rely on visual polish alone.
- [x] Use metrics in a considered hierarchy: a modest hero credibility cue, 3–4 major proof metrics, 2–3 contextual case metrics, and one final credibility cue; format numbers with visually dominant figures and concise descriptions, without overusing them.

## 8. Motion, interaction, responsive behavior and accessibility
- [x] Use controlled, responsive premium motion. Important headline reveals can animate by line/word/mask with subtle vertical translation and opacity, optional small blur resolving to clarity, 0.55–0.9 second duration, short 0.025–0.07 second stagger, and viewport entry triggering. Supporting copy gets simpler reveal. Never make visitors wait for animation.
- [x] Introduce content progressively with variation; animate visual hierarchy rather than everything simultaneously. Use only a few memorable scroll interactions (approximately 2–4): restrained parallax on large imagery, sticky storytelling/image, subtle image scaling or quick metric count-up. Avoid expensive movement and simplify/disable parallax on mobile.
- [x] Add restrained microinteractions: CTA arrow translation, animated underline, small image hover scale, project metadata reveal, smooth accessible accordion, and nav change on scroll where useful. No gimmicky interactions.
- [x] Respect `prefers-reduced-motion`. Keep the site fast: no unnecessary autoplay background videos, enormous uncompressed imagery, excessive scripts, dozens of simultaneous animations, expensive blur everywhere or heavy WebGL.
- [x] Ensure sufficient contrast, readable type sizes, keyboard-accessible interactive elements, visible focus states, semantic structure, reduced-motion support, obvious buttons and readability that is never sacrificed for art direction.
- [x] Design desktop as a wide cinematic composition, simplify overlaps on tablet, and redesign mobile for readability/conversion rather than merely shrinking desktop. Use considered spacing, vertical pacing, variable section density, full-width moments, constrained reading widths and occasional intentional asymmetry.
