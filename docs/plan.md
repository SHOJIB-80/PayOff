# PAYOFF — independent growth studio

## Implementation plan

Build a complete, single-page agency website in semantic HTML, CSS and vanilla JavaScript. No framework, backend, account system, database or heavy motion runtime is needed. It will be practical to rebuild in Elementor/Novamira: ordinary containers, Grid/Flexbox, careful positioning, sticky behavior, custom CSS, SVG and a small amount of JavaScript. The site is a designed editorial experience, not a stack of cloned sections. A separate handoff document will give the reason, copy and Elementor-friendly implementation for each section.

The brand name **PAYOFF** is a working creative recommendation, not a legal, trademark, social-handle or domain clearance. It names the commercial question the agency asks of every marketing move. Brand-owner details, actual client proof, contacts, team and approved testimonials are not supplied, so these remain unmistakably replaceable placeholders rather than invented facts.

### Project structure

- `index.html` — the full, accessible, single-page experience and editable copy.
- `styles.css` — design tokens, typography, bespoke section compositions, responsive and reduced-motion rules.
- `script.js` — navigation state, restrained section reveals, mobile menu and FAQ behavior; no dependency framework.
- `assets/images/` — locally packaged, optimized Pexels photographs for the hero, services, case-study format and selected-work examples; `assets/image-sources.md` records each source page, photographer, license and placement.
- `assets/payoff-mark.svg` — the hand-authored vector brand mark and favicon.
- `manus-routes.json` — root-route manifest.
- `elementor-novamira.md` — per-section objective, exact visible copy, layout/visual, interaction, responsive behavior and practical Elementor notes; it will also include the replace-before-launch items.
- `plan.md` — this plan and design system.
- `TODO.md` — outcome-based delivery state, created after plan approval.

Preview will use a small static HTTP server on the configured project port. The live page will use the uploaded `/manus-storage/` paths for photos, with matching optimized WebP files kept under `assets/images/` for the downloadable, portable package. No public publication is assumed.

## Creative direction

**Design movement:** an independent strategy journal crossed with a print-shop proof sheet: tactile, exact, slightly unexpected and commercially literate. Think annotated working papers rather than a polished SaaS interface. Use visual references selectively; do not imitate any existing website.

**Core principles:**
1. Explain the business decision before naming the channel.
2. Give proof its source; never turn a placeholder into a claim.
3. Make the page feel laid out by an art director: deliberate scale shifts, real whitespace and one memorable visual device, not repeated cards.
4. Use motion to reveal hierarchy, not to disguise thin content.

**Color philosophy:** paper white and charcoal-green ink create a grounded print surface; a sharp persimmon red is the decisive editing mark; a small chartreuse accent is reserved for route/measurement annotations. These are flat inks, not gradients or glows. Working tokens: paper `#F1EEE5`, ink `#17211D`, persimmon `#E65337`, chartreuse `#C6D36B`, and ash `#B8B5AC`.

**Layout paradigm:** an open editorial grid that shifts by section: a narrow folio/index rail, variable-width columns, oversized flush-left headlines, an occasional bleed, and one sticky case-study frame. A thin persimmon “decision rule” travels through the story and ends in a handoff arrow. Not every section gets a border, tile, card or centered headline. Mobile is re-composed: order is chosen for reading, wide systems become vertical, and overlaps/parallax disappear.

**Signature elements:** (1) a single printed red rule with crop/registration ticks; (2) small monospaced folio and margin annotations; (3) large expressive typographic moments with selective italic serif contrast. Reuse the elements as editorial navigation cues, not decoration on everything.

**Interaction philosophy:** quick, useful, optional. The initial view feels like an open editorial cover; after scroll, the nav settles into a quieter ink-on-paper bar. A few content reveals and a restrained large-screen sticky study frame support the narrative. Service details and FAQ remain simple, keyboard-operable disclosures. No custom cursor, scroll-jacking, gratuitous hover effects, glass cards, giant animated number gimmicks or decorative complexity without a content job.

**Animation:** CSS transitions and IntersectionObserver only. Use brief reveals for selected titles and section moments (roughly 0.55–0.8 seconds), but keep the hero and Services photos visible immediately; they do not depend on JavaScript or a mask reveal. Leave body copy readable immediately. Reduce/disable motion on `prefers-reduced-motion` and for small-screen parallax. Unverified figures remain static text placeholders; count-up is enabled only if a real numeric value is later supplied.

**Typography:** a contemporary grotesk for large display and body text (Manrope with system fallbacks), a contrasting editorial serif italic for one or two human phrases (Instrument Serif), and DM Mono for labels/data/indices. Headlines use a strong size range, tight but readable leading and short lines; body text keeps a restrained measure and adequate size. Font loading is non-blocking and all families have local fallbacks.

**Brand essence:** PAYOFF is a growth studio that repairs the handoffs between attention and repeat revenue; exact, unsentimental, curious.

**Brand voice:** commercially direct, human and specific—more operator's notebook than agency deck. Sample copy: “The handoff is where growth earns its keep.” “Buy less noise. Learn faster from the signal.” Buttons describe the next action, not vague ambition.

**Wordmark & logo:** PAYOFF is set as a purposeful typographic wordmark, paired with a custom small “handoff mark”: two offset rules joined by a sharp red notch, like a proof-sheet registration crossing a decision point. Draw the mark as SVG; never ask image generation to render the wordmark.

**Signature brand color:** persimmon red `#E65337`, used as an editing mark and route—not a large background gradient.

## Story architecture and visible copy direction

Keep the required breadth, but vary pace and visual weight. Some elements are a full-width visual event, some are a compact evidence band, some are quiet reading sections. The result should not read as a 19-item template. Exact content, per-section Elementor translation, interaction behavior and responsive notes will be supplied in `elementor-novamira.md`.

1. **Hero — a clear commercial point of view.** Working headline: “The handoff is where growth earns its keep.” Supporting copy: “PAYOFF connects strategy, creative, acquisition and conversion—so every next move has a better chance of paying for itself.” Primary CTA: “Find the growth constraint”; secondary: “Read the approach.” Layout: left-side typography like an opening magazine cover; right-side licensed Pexels photograph of a warm, brick-walled creative team reviewing work (Mikael Blomkvist, photo 6476255), cropped into a decisive rectangle with a fine persimmon edge annotation. Caption it as an illustrative stock working scene, not PAYOFF staff. Not a dashboard, floating 3D object or generated text. Add one small, honest credibility cue: “Strategy → acquisition → retention.” On mobile, headline, image and actions reorder into a fast, vertical introduction.
2. **Trust / client signal — show breadth without pretending.** A narrow run of editable industry labels and three proof slots (`$XXM+`, `XXX+`, `XX%`) marked `replace with verified agency data`; do not invent logos or experience. Use a rule-and-label strip rather than a row of badges. On mobile it wraps into a compact list.
3. **The business problem — show the expensive handoff.** Headline: “The leak is rarely the channel. It’s the gap between them.” Four staggered editorial observations: traffic without a landing-page decision; creative without a learning loop; spend without attribution; acquisition without retention. Each concludes with the business cost at stake. Use typography, an open margin and the traveling red rule; no icon grid. Mobile becomes a readable four-beat sequence.
4. **Point of view — explain the economics.** Copy: “A click is a cost. What happens after it decides whether it was worth buying.” Follow the decision chain from promise → offer → page → follow-up → repeat purchase, connecting it to margin and customer value. Oversized serif/sans contrast and a simple annotated line—not a fake interface. The audience can understand this without animation.
5. **Services — define the work in outcome terms.** A numbered, keyboard-operable index, not a 6-card grid. Cover growth strategy, paid acquisition, creative strategy, content systems, landing pages, conversion optimization, funnels, email/retention and analytics/attribution. Each opened service states **what it is**, **why it matters**, and **the business outcome it connects to**. Below the list, add one wide overhead Pexels photo of a creative team working with color swatches (Vitaly Gariev, photo 39190497), captioned as illustrative stock rather than PAYOFF staff. The list keeps editorial density on desktop and uses expanded reading rows on mobile.
6. **Performance proof — leave room for verified facts.** Headline: “Make the economics move, not just the activity.” Four oversized, editable slots: `XX%` qualified pipeline, `X.X×` return, `XX%` lower acquisition cost, `$X.XM` revenue influenced. Each is clearly labeled “illustrative placeholder — replace with a verified result.” Set them on a deep ink sheet divided by one fine rule, with no fake chart. On mobile, each stat gets clear space; animation/count-up waits until verified numeric values are supplied.
7. **Featured case study — show the causal chain, not a boast.** Full-bleed paper-to-ink transition and a licensed Pexels photo of a team reviewing a graph on-screen (Mikael Blomkvist, photo 6476259), expressly captioned as illustrative stock photography—not client work. Mark the panel “Case study format — replace with approved client work.” Story fields: `[Client / industry]`, `[Business challenge]`, `[What the evidence revealed]`, `[Strategic decision]`, `[Execution]`, `[Verified outcome]`; use 2–4 metric slots. A restrained sticky image is allowed on desktop; mobile turns it into a normal opening image followed by the complete story.
8. **Selected work — show range without invented client wins.** Three asymmetrically sized, image-led “example slots” with `[Client]`, `[Challenge]`, `[Service]`, `[Measured outcome]` and `[Approved visual asset]`. Use three distinct licensed stock photos (Pexels photos 12903281, 17713779 and 3182763), each visibly labeled as an illustrative format image and not a client asset. Until supplied, identify examples as formats—not client work. No made-up performance claims. At small widths, each example becomes a distinct stacked article with a considered 4:3 crop, not a tiny card.
9. **Method — make the process feel repeatable.** Six clear decisions, written as action phrases: **Find the constraint → Choose the lever → Build the handoff → Put it in market → Read the economics → Reinvest what works.** Use a large left-edge number, printed rule and brief working note at each stage. Mobile turns the path into a clean vertical timeline.
10. **Journey — explain how services connect.** An educational system: **Attention → Acquisition → Conversion → Retention → Expansion**, each with the relevant work and a direct business question. Create a precise, bespoke SVG/HTML route graphic; no AI-generated chart. Desktop runs laterally across the page; mobile makes a vertical path with legible labels.
11. **Differentiation — prove the operating model.** Editorial statements, not corporate value labels: “Senior strategy stays close to the work.” “Creative is judged against performance, not taste alone.” “A weekly learning loop changes the next decision.” “Reporting reaches revenue, not just reach.” Include deliberate experimentation, not activity for its own sake. These appear as a typographic sequence, not repeated cards.
12. **Experimentation — show the learning loop.** **Hypothesis → Build → Launch → Measure → Learn → Scale**, with clearly named testable levers: messaging, creative, audience, offers, landing pages and funnel steps. Use stamps/notations along a fine route to show iteration. Keep copy/data illustrative, never imply experiments were actually run.
13. **Client voice — reserve space for an approved quote.** Large single quotation area reading `[Insert an approved client quote here]`; `[Name]`, `[Position]`, `[Company]`, optional `[Verified outcome]`. Explicitly marked “placeholder — replace with approved client wording.” No fake testimonials, carousel or generated client identity.
14. **Working rhythm — make the engagement visible.** **Weekly:** performance snapshot. **Biweekly:** creative and experiment review. **Monthly:** strategic growth review. **Always:** shared reporting visibility. Use a working-calendar/field-note composition with deliverable and decision points. Policy details are editable/subject to verification; mobile preserves the time cadence.
15. **People and expertise — be human without inventing a team.** A short editorial block with `[Lead strategist portrait]`, `[Name]`, `[Relevant experience]`, `[Specialty]` and `[Working philosophy]`. No stock working photo may be presented as a real PAYOFF team portrait; keep this slot visibly marked for an approved portrait and use no fabricated biography. Layout: one large portrait aperture and annotated bio, then stacked on mobile.
16. **Client fit — qualify with clarity.** **Best fit:** an established business with proven demand and a real acquisition or retention constraint. **Probably not:** a buyer seeking overnight hacks, disconnected channel output or a vanity-metric report. Two contrasting columns joined by the signature rule; simple, vertically stacked on mobile.
17. **FAQ — handle real objections.** Keyboard-accessible disclosures covering start timing, business size, creative, contract length, reporting, working with an in-house team, onboarding and how success is measured. Use cautious, editable answers for policies the owner has not supplied and mark them for confirmation before launch. No invented contract terms, guarantees, minimum spend, or start date.
18. **Final conversion — ask for one useful next step.** Headline: “Let’s find where growth stops paying back.” CTA: “Book a Growth Strategy Call.” Exact microcopy: “30 minutes. No generic sales deck. We identify where growth is currently leaking.” Use a cropped paper/ink visual echo of the hero, but a new crop and stronger red mark so it feels like a conclusion, not a repeated hero. Mobile places the CTA before decorative media.
19. **Footer — finish like a designed publication.** Large PAYOFF wordmark, compact **Services / Work / About / Contact / Insights** navigation, social/privacy/terms, and editable location/contact fields. Until real URLs exist, use clearly marked inert placeholders, not invented social accounts or fake email addresses. A fine registration mark/return-to-top detail signs off the page. Desktop uses editorial columns; mobile stacks accessible links.

## Responsive, accessible and performance behavior

Use semantic landmarks, correct heading hierarchy, sufficient contrast, visible focus, descriptive alternatives and keyboard-operable navigation/disclosures. Keep body copy readable and buttons obvious. Mobile gets intentional reorderings, comfortable tap targets, shorter headings, verticalized timelines and journey logic; disable nonessential parallax, sticky media and layered overlaps. Support `prefers-reduced-motion`; content remains visible if JavaScript is unavailable. Use locally packaged, optimized Pexels assets, load below-the-fold photos lazily, keep the hero image eager, and use responsive object-fit crops with art-directed object positions; no autoplay video, heavy blur or UI-library runtime. Source notes record the image pages and Pexels license. Do not use watermarked Unsplash+ previews or unlicensed Pinterest reposts, and do not imply stock subjects endorse PAYOFF. Add a useful page title, description, theme color, favicon and root-only route manifest. All fake-able facts remain visibly bracketed/placeholder-marked and easy to edit.

## Elementor / Novamira handoff

`elementor-novamira.md` will document the palette, fonts, spacing, grid, brand mark, type hierarchy, buttons, recurring line/tick motif, image direction, motion rules, reusable components and replace-before-launch fields. Then it will map every section plus footer to: purpose, layout/composition, final visible copy, visual direction, interaction, mobile behavior and an Elementor structure/setting recipe. Use ordinary containers and widgets, sticky position where appropriate, limited custom CSS, and optional limited GSAP only if desired; no section depends on WebGL, a bespoke backend or complex JavaScript.
